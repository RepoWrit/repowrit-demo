## How It Works

When you connect a repository to RepoWrit:

1. **Every push** triggers Claude 4.5 to analyze the commit diff.
2. **Documentation PRs** are opened automatically on the `repoWrit/docs-update` branch.
3. **Executive Briefings** synthesize recent activity into leadership-ready summaries.
4. **Architecture Maps** (Scale plan) visualize your module structure and dependency graph.

This demo repo shows the output of step 3. To see the full experience — automatic docs, semantic search, and architecture mapping — [install RepoWrit](https://repowrit.com) on your own repositories.
